如何透過 QR Code 掃碼安裝本應用程式

📱 手機掃碼安裝：APK 下載與 App QR Code 產生器

貼上你的 GitHub Releases .apk 下載連結或 GitHub Pages 網址，立即生成高解析度 QR Code 供手機相機掃描安裝。

掃碼安裝流程說明：
  1. Android APK 直接下載：將 GitHub Actions 編譯出的 app-debug.apk 上傳至 GitHub Releases [cite: 1.1.3, 1.1.5]，貼上該下載連結生成 QR Code，手機掃描後即可直接下載安裝。
  2. 免編譯網頁 App（PWA）：若將本專案託管於免費的 GitHub Pages 或 Vercel [cite: 1.2.2, 1.2.4]，貼上網頁網址生成 QR Code，iPhone 與 Android 掃碼開啟後「加入主畫面」即可變成獨立 App。
📱 iPhone / iPad (Safari)
  1. 使用 Safari 開啟本網頁檔案或託管網址。
  2. 點擊下方工具列的「分享」圖示（方框向上箭頭）。
  3. 往下滑動並選擇「加入主畫面」，即可在桌面以獨立全螢幕 App 啟動。
🤖 Android / 電腦版 Chrome
  1. 使用 Chrome 瀏覽器開啟本應用程式頁面。
  2. 點擊右上角「⋮」選單。
  3. 選擇「安裝應用程式」或「加到主畫面」即可完成離線快取安裝。
GitHub Actions 每日自動更新排程腳本 (.github/workflows/daily_sync.yml) 
name: Daily Election Environment Sync
on:
  schedule:
    - cron: '0 0 * * *' # 每日台灣時間 08:00 自動執行
  workflow_dispatch:
jobs:
  update-data:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: python scripts/run_ols_calibrated_model.py --locked-mode
      - run: |
          git config user.name "ElectionBot"
          git config user.email "bot@users.noreply.github.com"
          git add data/latest_calibrated_intervals.json
          git commit -m "chore: daily locked environment calibration sync" || exit 0
          git push
